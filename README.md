# Reels Downloader\n\n## Auto Share → Resolve → Download\n\nThe Android app receives a shared Instagram link and sends it to the backend resolver. The backend is now Python-based and uses yt-dlp for publicly accessible media.\n\n### Backend files\n\n- `backend/app.py` — Flask API\n- `backend/requirements.txt` — Python dependencies\n- `backend/Dockerfile` — Render Docker deployment\n\n### API\n\n`POST /resolve`\n\nRequest:\n\n`{\"url\":\"https://www.instagram.com/reel/.../\"}`\n\nOn success, the resolver returns a direct media URL for media that is publicly accessible. Private, login-required, deleted, or otherwise restricted media is not bypassed.\n\n### Render deployment\n\nSet the service root directory to `backend` and deploy it as a Docker service so the Python environment is used. The Dockerfile starts:\n\n`gunicorn --bind 0.0.0.0:$PORT app:app`\n\nyt-dlp is actively updated and platform compatibility can change, so keep the dependency updated when necessary.\n
